# 管理后台仪表板

## 概述

管理后台仪表板是文风字库的核心管理界面，为管理员提供系统概览、统计信息和快速操作入口。

## 功能特性

### 1. 统计信息卡片

显示系统的关键指标：

- **总字体数**: 系统中所有字体的数量
- **品牌数**: 字体品牌商的数量
- **分类数**: 字体分类的数量
- **总浏览量**: 所有字体的累计浏览次数
- **总下载量**: 所有字体的累计下载次数

每个统计卡片都配有相应的图标，使界面更加直观。

### 2. 快速操作区域

提供常用管理功能的快捷入口：

- **添加字体**: 快速跳转到字体创建页面
- **添加品牌**: 快速跳转到品牌创建页面
- **添加分类**: 快速跳转到分类创建页面
- **同步字体**: 快速跳转到字体同步页面

### 3. 最近更新的字体

显示最新添加或更新的 5 个字体，包含：

- 字体名称（可点击跳转到详情）
- 所属分类（Badge 显示）
- 所属品牌（Badge 显示）
- 更新时间

支持"查看全部"链接跳转到完整的字体管理列表。

### 4. 热门字体

按浏览量排序显示前 5 个热门字体，包含：

- 字体名称（可点击跳转到详情）
- 所属分类（Badge 显示）
- 浏览量（带图标）
- 下载量（带图标）

支持"查看全部"链接跳转到按浏览量排序的字体列表。

## 技术实现

### 数据获取

使用 Next.js 15 的 Server Components 特性，在服务端直接获取数据：

```typescript
// 获取统计信息
const stats = await fontService.getStats();

// 获取最近更新的字体（带关联数据）
const recentFonts = await fontService.getLatestFontsWithRelations(5);

// 获取热门字体（带关联数据）
const popularFonts = await fontService.getPopularFontsWithRelations(5);
```

### UI 组件

使用 shadcn/ui 组件库构建界面：

- `Card`: 统计卡片和内容区域
- `Button`: 快速操作按钮
- `Badge`: 分类和品牌标签
- `Table`: 字体列表展示
- `lucide-react`: 图标库

### 布局

使用 `AdminLayout` 组件提供统一的管理后台布局，包含：

- 顶部导航栏（AdminHeader）
- 侧边栏（Sidebar）
- 主内容区域

### 响应式设计

- 统计卡片使用 Grid 布局，在不同屏幕尺寸下自适应：
  - 移动端：单列
  - 平板：2 列
  - 桌面：5 列
- 字体列表区域在大屏幕下并排显示，小屏幕下堆叠

## 权限控制

仪表板页面使用 `requireAuth()` 函数进行权限验证：

```typescript
const session = await requireAuth();
```

只有已认证的管理员才能访问此页面，未认证用户会被重定向到登录页面。

## 性能优化

1. **服务端渲染**: 使用 Next.js Server Components，数据在服务端获取，减少客户端请求
2. **数据库优化**: 使用带索引的查询，提高数据获取速度
3. **限制数据量**: 最近更新和热门字体只显示前 5 条，避免加载过多数据
